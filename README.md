# Rossmann Sales Analysis & Visualization (Streamlit + Statistics)

Performed statistical analysis and exploratory data analysis (EDA) on Rossmann sales dataset.

Analyzed sales trends, seasonality, promotions, and store-wise performance.

Applied descriptive statistics and correlation analysis for business insights.

Developed interactive dashboards using Streamlit for real-time visualization.

Enabled dynamic filtering and comparison of sales metrics.

Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn, Streamlit
